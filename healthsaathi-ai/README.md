# HealthSaathi AI

A responsive, standalone front-end prototype for a health and wellness companion.

## Run locally
Open `index.html` in a modern browser.

## Deploy on Vercel
Import this folder/repository into Vercel as a static site. No build command is required; set the output directory to `.` if prompted.

## Included
- Responsive dashboard and navigation
- Local hydration counter
- Rule-based demo wellness chat
- Health notes, medicine reminders, and appointments (session-only; not persisted)
- Medical safety disclaimer

## Important limitations
This prototype is not connected to a live AI service, authentication, a database, or medical records. The chat uses local rules and must not be relied on for emergency detection or medical advice. Do not enter sensitive health information.
